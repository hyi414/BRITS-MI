# Archived Diagnostics

These scripts document development-time numerical checks and figure assembly.
They may require locally generated simulation caches or manuscript layout
assets that are not distributed. Use `../run_simulation.py` for new experiments
and `../plot_results.py` for the public synthetic-result visualization path.

The original result identifiers are retained to identify the analysis inputs;
they are not additional package entry points. No private cohort data are needed
for the simulation diagnostics or included here.

# Data and privacy policy

This repository excludes individual-level clinical data. It contains synthetic-data
generators, model code, tests, configuration files, and aggregate results. The
Vanderbilt elastography cohort and any derived patient-level tensors are not
redistributable and must remain in their approved computing environment.

Before publishing a release:

1. Inspect the Git history, not only the current working tree, for identifiers,
   paths, credentials, clinical extracts, and fitted restricted-data objects.
2. Publish only aggregate tables that satisfy the governing disclosure rules.
3. Replace any provisional repository URL or release tag in the manuscript
   after the public archive has been created.
4. Archive the exact release in a DOI-minting repository when permitted.

# Reported-analysis map

This directory records how the locked manuscript analyses relate to the
compact `brits_mi` package. Read it before attempting to reproduce a
manuscript table.

## Clinical-association benchmark

The reported 500-subject benchmark was orchestrated by
`simulation/clinical/scripts/run_refined_brits_mi_association.py`. Its recurrent
proposal uses cross-fitted forward and backward RITS-GRU passes, artificial
holdouts, trajectory-summary loss, and a downstream classification loss. The
reported completion distribution then uses an outcome-blind R `missForest`
conditional-mean anchor and retains a development-selected fraction of the
neural mean and residual spread. The default weights were 0.10 for the neural
mean correction at 20% and 40% missingness, 0.20 at 60%, and 0.70 for residual
spread. This composite implementation is the BRITS-MI arm reported in the
clinical-association tables.

The `simulation/clinical/scripts` folder contains the exact dependency chain used by
that orchestration. These archival scripts preserve historical module names
and are intentionally not installed as part of the public Python API. The
small aggregate result files under `results/clinical_association_n500` and
`results/clinical_association_n2000` contain no patient-level data.

## Compact public API

The installable package under `src/brits_mi` provides a clean implementation
of the reusable method components: bidirectional RITS-GRU conditional means,
artificial masking, the weighted downstream-aware objective, validation-based
model selection, stochastic completed trajectories, Rubin pooling, and an
optional bounded association-score calibration. It does not reproduce the
historical missForest anchor automatically. This distinction prevents a smoke
example from being presented as a byte-for-byte regeneration of the paper.

## Clinical-image prototype benchmark

The locked 500-run clinical-image benchmark was generated by
`simulation/image/scripts/run_fast_image_fusion_nsim500.py`. In that historical
experiment, the arm labeled BRITS-MI used image-conditioned extremely
randomized trees with a class-prototype correction, while the arm labeled
missForest used a random-forest surrogate. It was a developmental
image-conditioned prototype, not a run of the recurrent package and not a
package-default R `missForest` comparison. Its aggregate values and paired
tests are retained under `results/clinical_image_prototype` for auditability.

## Real observed-cell masking analysis

The portable masking code is in `validation/`. Aggregate method summaries and paired comparisons remain under
`results/real_masking`. The restricted cohort, patient-level tensors, fitted
objects, and row-level masks are excluded. Reproduction therefore requires an
authorized analysis-ready dataset satisfying `docs/data_contract.md`.

## Publication checklist

Before public release, replace provisional manuscript links with an immutable
tag, archive that tag in a DOI-minting repository, and confirm that the final
manuscript wording preserves the distinctions above. Do not upload raw or
derived patient-level clinical data.
